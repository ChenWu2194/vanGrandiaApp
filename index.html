Fuel assumptions (shared)

“×” = how much more fuel is used than in free flow. Defaults: ₱100/L, 9 km/L, severe = 2× (≈4.5 km/L). Compare with real refuels and adjust.

Shared database (GitHub)

How to get the token
  1. GitHub → profile photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → pick the data repo.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Copy the token and paste it above. Each teammate does this once on their own phone (or share your token privately).

Install on your phone

Android (Chrome): ⋮ menu → Install app / Add to Home screen.
iPhone (Safari): Share button → Add to Home Screen.
Bookings you view are kept on the phone, so the app still opens without signal. Changes made offline upload when you're back online.
