# Grandia Van Rental Desk (app)

Static phone-friendly app: fuel-cost estimator, booking calendar and payments.
This repo holds **code only**. Bookings live in the private repo `ChenWu2194/VanGrandia` (`data.json`), which each phone reaches with its own access token (Settings tab).

Publish: Settings → Pages → Deploy from a branch → `main` / `(root)`.
